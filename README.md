# DCI HEM AI

This repository contains supporting material for work involving DALY-CARE data and the safe use of AI in hematology research.

## Repository contents

- [`FAQ/`](./FAQ/) — questions about data use and safe AI usage
- [`methods/`](./methods/) — methods extracted and summarized from the DALY-CARE publications
- [`metadata/`](./metadata/) — DALY-CARE clinical metadata summaries and extraction code
- [`mock_data/`](./mock_data/) — mock DALY-CARE data for development and testing
- [`presentation/`](./presentation/) — presentation material
- [`publications/`](./publications/) — publication summaries and full-text papers

## Important notes

- The full-text source papers are available in the [`publications/`](./publications/) folder.
- Mock data must not be used to draw clinical or epidemiological conclusions.
- Clinical metadata summaries contain aggregate information only, not patient-level records.
- AI-generated material should be reviewed and validated before use in research or clinical contexts.
